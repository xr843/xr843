## Hi, I'm Tim Ren

Full-stack developer focused on **Buddhist digital humanities** — building open-source tools that make ancient texts accessible to modern researchers.

### Buddhist Digital Humanities

- **[FoJin 佛津](https://github.com/xr843/fojin)** &nbsp; ![GitHub stars](https://img.shields.io/github/stars/xr843/fojin?style=flat-square&label=stars) — The world's encyclopedic Buddhist digital text platform. 483 sources, 30 languages, full-text reading, AI Q&A, knowledge graph, parallel reader. FastAPI + React + Elasticsearch.

- **[Buddhist Text Punctuation](https://github.com/xr843/buddhist-text-punctuation)** &nbsp; ![GitHub stars](https://img.shields.io/github/stars/xr843/buddhist-text-punctuation?style=flat-square) — AI-powered punctuation and collation research platform. OCR, multi-version collation, phylogenetic analysis, CBETA integration. FastAPI + React.

- **[Buddhist Glyph Library](https://github.com/xr843/buddhist-glyph-library)** &nbsp; ![GitHub stars](https://img.shields.io/github/stars/xr843/buddhist-glyph-library?style=flat-square) — Character search and analysis across 7 historical scripture editions. Siamese network similarity search, OCR integration. React + FastAPI.

- **[Abhidharma RAG Q&A](https://github.com/xr843/abhidharma-nyay-nus-ra-rag)** — RAG-powered Q&A for Buddhist Abhidharma research. GuwenBERT vector search + DeepSeek LLM over 10,401 text segments. Vue 3 + FastAPI + ChromaDB.

- **[Scripture Image Alignment](https://github.com/xr843/scripture-image-alignment)** — Multi-version scripture image-text alignment. Character-by-character comparison with OCR and sequence matching. Flask + Python.

- **[Buddhist AI Translator](https://github.com/xr843/Buddhist-AI-Translator)** &nbsp; ![GitHub stars](https://img.shields.io/github/stars/xr843/Buddhist-AI-Translator?style=flat-square) — AI translation for Buddhist texts across Sanskrit, Pali, Tibetan, and Classical Chinese.

### Other Projects
